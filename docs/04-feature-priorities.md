## 2. Explicit Exclusions (Out of Scope)
- Real-time 3D webGL / CAD rendering (2D SVG vector previews are intentionally used for speed & low friction)
- AR / VR camera viewports
- Live e-commerce shopping cart & contractor booking
- External backend server dependency (pure client-side execution with local persistence)
