# Phase 1 — Screen Inventory & UX Principle Mapping

## Screen Inventory Overview

| Screen ID | Title | Key Interactive Components | Primary CTA | UX Principle Enforced |
|---|---|---|---|---|
| `landing` | Landing Page | Nestora Logo, Nesto Companion, Feature Cards, How It Works | Start Building My Nest | Von Restorff Effect, Aesthetic-Usability |
| `onboarding` | Onboarding | Benefit Slides, Mascot Expressions | Continue / Skip | Progressive Disclosure |
| `dashboard` | Dashboard | Active Projects, Drafts, Recent Inspirations, Nesto Tip | Create New Nest | Zeigarnik Effect, Hick's Law |
| `wizard` | Room Configurator | Step Progress, Option Cards (Space, Style, Budget, Lighting) | Continue to Recommendations | Miller's Law, Goal-Gradient Effect |
| `recommendations` | Recommendations | 3-5 Curated Palette Cards, "Why This Works", "Why Not" | Select Design to Customize | Hick's Law, Recognition over Recall |
| `visualizer` | 2D Workspace | Interactive SVG Scene, Swatch Controls, Lighting Toggles | Save Version / Compare | Fitts's Law, Visibility of System Status |
| `compare` | Compare View | Side-by-side versions, Rating Radar, Metric Chips | Choose Winning Design | Miller's Law, User Control and Freedom |
| `completion` | Nest Completed | Confetti, Nest Score Breakdown Card, Summary Export | Save & View My Nest | Peak-End Rule, Zeigarnik Effect |
| `my_nest` | My Nest | Active, Draft, Completed tabs, Project cards, Delete confirm | Resume / Duplicate | User Control and Freedom |
| `inspiration` | Inspiration | Style filters, High-res preview cards, Palette breakdown | Apply Style to Nest | Recognition over Recall |
| `wireframes` | Low-Fi Wireframes | Phase 2 structural wireframe walkthrough | Next Wireframe Step | Jakob's Law |
| `design_system` | Design Tokens | Color swatches, Typography, Component Showcase | Toggle States | Gestalt Similarity |
| `ux_study` | UX Rationale | Heuristic reference, Law definitions, Research mapping | Return to App | Recognition over Recall |
| `profile` | Profile & XP | Level progress bar, Baya Weaver rank, Data reset | Update Profile | Goal-Gradient Effect |
